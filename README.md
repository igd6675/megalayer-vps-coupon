## 家宽 VPS：这 80 元/月买的到底是什么

家宽 VPS 卖的是 IP 属性，不是算力。官方对它的定义是“家庭带宽 VPS，可以理解为家庭住宅 IP VPS”，用来解锁美国电视、流媒体、游戏这类场景。

配置上，1核1G 起，1 个管理 IP + 1 个住宅 IP，优化带宽 15M，挂牌价 160 元/月，五折后 80 元/月起。可升级范围是 1 到 10 vCPU、1 到 16G 内存、50 到 200G SSD、15 到 50Mbps 带宽，流量不限。测试 IP 是 `104.247.120.254`，下单前可以先 ping 一下看看走什么线路。

两个实操细节：住宅 IP 是静态的，要换得发工单，不能自己在面板上点；想知道业务流量实际从哪个 IP 出去，Linux 下跑 `curl ifconfig.me`，Windows 直接浏览器访问 ifconfig.me。

这产品不适合谁？拿它做国内访问的站点不划算。15M 优化带宽比常规 VPS 的 10M、20M 档没优势，价格却是 3 倍多。它值钱的地方在于那个住宅 IP，注册美区账号、做云上美国人这类用途才对得上成本。

## 下单前必须知道的四条限制

下面这些出自官方活动公告的注意事项原文，属于“活动机器”的规则，不是全站政策：

1. **活动机器不支持退款**，下单前确认清楚。资料里没有全站退款政策页面，别把这条理解成所有产品都不能退。
2. **付款后订单进入审批（pending）状态**，机器按序通过邮件交付。急着当天开通的人要留出等待时间。
3. **升级部分按原价计费**。活动套餐加 CPU、内存、硬盘、IP，加的那部分不享受折扣。
4. **叠加规则有限制**。当年的公告里，只有可升级 VPS 9 折那一档能和季付 95 折、买五赠一、买十赠二同享；家宽 5 折和年付立减 10 元都不与季付折扣同享。第三方页面也提到活动特价套餐通常不支持同享季付、半年付折扣。

可升级范围官方写得很明确：CPU 最高 10 核，内存最高 16G，硬盘最高 200G，IP 最多增加到 9 个。

## 常见问题

**优惠码在哪里填？**
购物车或结账页有优惠码输入框，填入后点应用，价格立刻重算。不同套餐适用的码不一样，一个码用不了就换表里对应的那个。

**为什么我下单没打折？**
三种可能：码和套餐不匹配（比如拿 VPS 码去结独服）、活动期已过、这个套餐本身已经是特价不再叠加。第三种在活动页的叠加规则里写得很清楚。

**续费会涨回原价吗？**
官方活动公告写“所有产品均续费同价”，第三方测评也确认了这一点。按这个说法，当前价格就是长期价格。但公告是 2023 年的，实际续费金额以你自己后台的续费账单为准。

**家宽 VPS 的 IP 真的是住宅 IP 吗？**
官方称其为“家庭带宽 VPS”，配置为 1 个管理 IP + 1 个住宅 IP，第三方测评页面的描述一致。IP 是静态的，更换需要发工单。

**能退款吗？**
活动公告明确写活动机器不支持退款。这条只针对活动套餐，资料里没有全站退款政策的说明。

**香港和美国机房怎么选？**
看重国内访问延迟选香港，2M 优化（CN2）带宽小但线路直；看重带宽和流量成本选圣何塞，同样价格能拿到 10M 甚至 20M。有测评称香港 CN2 延迟在 30 到 40ms、圣何塞在 150ms 左右，这是第三方说法，我没有实测过，只当参考。
